# 📡 InfoCasting

Агрегатор статей, Telegram-каналів і Reddit у стилі Tinder + RSS-рідер — брат [MovieCasting](https://github.com/zharoslaw31/MovieCasting) і [CookCasting](https://github.com/zharoslaw31/CookCasting). Англійське **перекладається українською**, а цінне одним рухом **зберігається в Obsidian** (з перекладом, оригіналом і коментарями Reddit). Працює на **Android та iPhone** (як сайт-застосунок), безкоштовний і без реєстрації.

**Відкрити:** https://zharoslaw31.github.io/InfoCasting/

| Розділ | Що вміє |
|---|---|
| 🔥 **Кастинг** | Картки матеріалів: свайп **вправо** — прочитаю пізніше, **вліво** — пропустити, **вгору** — одразу в Obsidian. Скасування, перемішування, клавіші ← → ↑ на комп’ютері. Режими **🎲 Усе** і **✨ Для тебе** (підбір за улюбленими джерелами й темами), фільтр 📰 Блоги / ✈️ Telegram / 👽 Reddit. |
| ☕ **Що почитати?** | Тема (Новини, Покликання, Ресурс, Сенс) + скільки є часу (3 хв … довге читання) + стаття / обговорення / новини → 5 варіантів, «Обери за мене». |
| 🗞 **Стрічка** | Класичний RSS-рідер: усе разом або окремо блоги, Telegram, Reddit; напрямки й групи з бази, окремі джерела, пошук, «лише непрочитане», «позначити все прочитаним», UA/EN одним дотиком. |
| 📖 **Читалка** | Повний текст (якщо блог дає лише анонс — добирається зі сторінки статті), переклад українською з перемиканням на оригінал, коментарі Reddit з перекладом, «сайт українською» через Google Translate, поділитися. |
| 📚 **Бібліотека** | Прочитати пізніше, Збережене в Obsidian (зі шляхом до нотатки), Прочитане, Пропущене; пошук. |
| 👤 **Профіль** | Статистика читання, налаштування Obsidian і перекладу, стан джерел, «Зібрати зараз». |

## Звідки джерела

Списки взято з бази Obsidian (репозиторій BAZA): **126 блогів і журналів** (`BAZE-блоги.opml`), **144 сабреддіти** у 25 групах (`BAZE-reddit.opml`) і **25 Telegram-каналів** (нотатка «Телеграм»). Теми з OPML (`покликання/маркетинг`, `ресурс/сон` …) стають тегами збережених нотаток.

Оновили списки в базі — скопіюйте файли в `scripts/baza/` і запустіть `node scripts/import-baza.mjs`, або правте `scripts/sources.json` напряму.

## Як це працює

GitHub Actions (**Update feed**) кожні 30 хвилин запускає [`scripts/build-feed.mjs`](scripts/build-feed.mjs):

1. збирає RSS/Atom блогів, публічні сторінки Telegram-каналів (`t.me/s/…`) і Reddit;
2. ховає пости-оповіщення про тривоги (та сама логіка, що й у базі);
3. для статей, де стрічка дає лише анонс, добирає повний текст зі сторінки (як «режим читання»);
4. перекладає англійські заголовки й анонси українською (Google Translate, пам’ять перекладів у `cache.json`);
5. кладе результат у гілку **`data`**: `feed.json` + `c/<id>.json` з повними текстами.

Додаток бере дані звідти, а повний текст і коментарі перекладає вже на пристрої (переклад кешується). Свіжі матеріали тримаються: блоги — 14 днів, Reddit — 7, Telegram — 4.

## 👽 Reddit

Без ключа Reddit відповідає серверам GitHub лише на кілька запитів поспіль, тож групи сабреддітів оновлюються по черзі, а коментарі вантажаться з вашого пристрою, коли відкриваєте допис. Щоб Reddit оновлювався повністю й з коментарями, потрібен безкоштовний ключ API:

1. https://www.reddit.com/prefs/apps → **create another app** → тип **script**, redirect uri `http://localhost` (Reddit може попросити погодити доступ до API);
2. у репозиторії **Settings → Secrets and variables → Actions** додайте `REDDIT_CLIENT_ID` (рядок під назвою застосунку) і `REDDIT_CLIENT_SECRET`.

## 💎 Obsidian

Кнопка «В Obsidian» відкриває вікно збереження: назва, тема з «Тем» бази (покликання / ресурс / сенс), свої думки (стають «3 ключовими думками»), статус (хочу / читаю / прочитано). Свайп вгору в Кастингу зберігає одразу з темою джерела.

Збережене стає нотаткою-джерелом у `2 Знання/2.3 Джерела` у тому ж форматі, що й кнопка «📚 У Джерела» в базі: властивості (`тип/джерело`, `стан/зерно`, тема, автор, посилання, обкладинка), «Про що це», «3 ключові думки», «Матеріал» (переклад + оригінал у згорнутій виносці `[!quote]- Оригінал`), коментарі Reddit, «Що з цього виросло». Способи (Профіль → Obsidian):

- **GitHub** (основний) — нотатка комітиться одразу в репозиторій бази, Obsidian Git підтягне її на всі пристрої. Профіль → Obsidian веде крок за кроком: кнопка відкриває GitHub з уже заповненим токеном (лишається вибрати репозиторій BAZA), вставити, «Перевірити й підключити». Токен можна зберігати в акаунті — тоді база працює на всіх пристроях після входу.
- **Obsidian** — відкривається Obsidian на цьому пристрої (`obsidian://new`).
- **Файл .md** — завантаження файлу.

## 👤 Акаунт і синхронізація

Вхід за email і паролем, як у MovieCasting і CookCasting, і той самий акаунт. Відкладене, збережене в Obsidian, прочитане, пропущене, вимкнені джерела й налаштування зберігаються в хмарі й доступні на всіх пристроях. Токен GitHub для Obsidian у хмару не потрапляє. Без входу все зберігається лише на пристрої.

Налаштування (один раз):

1. У Supabase виконайте [`supabase/info_libraries.sql`](supabase/info_libraries.sql) (SQL Editor → Run).
2. У Supabase → Authentication → URL Configuration → Redirect URLs додайте `https://zharoslaw31.github.io/InfoCasting/`.
3. У цьому репозиторії додайте секрет Actions `SUPABASE_ANON_KEY` (те саме значення, що в CookCasting) і перезапустіть «Publish website».

## 🌐 Встановити на телефон

- **iPhone (Safari):** «Поділитися» → «На початковий екран».
- **Android (Chrome):** меню ⋮ → «Додати на головний екран».

Кожна зміна в `main` публікується на GitHub Pages за 2–3 хвилини.
